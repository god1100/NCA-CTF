
# 22. Leaderboard Rules

Leaderboard ranking should use:

```text
Total Points
```

and a deterministic tie-breaker.

Recommended:

```text
1. Total points
2. Earliest time reaching that score
```

This creates a standard CTF-style ranking system.

# 54. MonkeyCode Debugging Workflow

When something breaks, do NOT say:

```text
Fix everything.
```

Instead:

```text
The login API is returning HTTP 500.

Here is the error:

[PASTE ERROR]

Investigate only the authentication module.

Do not rewrite unrelated components.

Identify the root cause first.

Then propose the smallest safe fix.

After applying the fix, test the login flow.
```

---

# 55. Never Hide Errors

MonkeyCode should not:

```text
Suppress exceptions
Remove error handling
Disable security checks
Hardcode credentials
```

to make the application "work."

If something fails:

